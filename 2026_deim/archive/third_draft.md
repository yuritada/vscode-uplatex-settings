# Model Context Protocolを用いた二層知識継承による建築制約を持つ屋内シーン生成の自律的品質保証

**著者:** 多田 有里 (武蔵野大学), 中村 亮太 (武蔵野大学)

---

## 和文あらまし
近年の生成AIの進展により、Text-to-3D技術は飛躍的な視覚的品質を達成したが、物理的・工学的整合性を欠く「**幾何学的ハルシネーション**」という課題が残っている。

本研究では、**Model Context Protocol (MCP)** を基盤とした自律的品質保証フレームワークを提案する。LLMとBlenderを数値データ（座標、法線、寸法）に基づいて接続し、「生成・検査・修正」サイクルを自律的に実行する。不変の「規制知識」と適応的な「経験知識」の二層構造により、知識の蓄積が自律性スコアを向上させ、トークン消費量を約58%削減することを実証した。

---

## 1. はじめに

### 1.1 研究の背景：視覚的「自然さ」から構造的「整合性」へ
既存のText-to-3D技術が生み出す成果物は、レンダリング画像としての「見た目」は優れているが、構造的な整合性に欠陥を抱えることが多い。
本研究では、3D空間上の幾何学的制約 $C$（例：接地性 $Z_{min}=0$、非干渉性 $V_{overlap}=0$）を満たさない状態（$C(S) = \text{False}$）を「**幾何学的ハルシネーション**」と定義する。これは、2D画像への射影過程で情報が欠落するために生じるエラーである。

### 1.2 研究の目的
数値データに基づく厳密な検査のみを用いた自律的品質保証フレームワークを構築し、幾何学的整合性の保証と推論コストの最適化を定量的に実証することを目的とする 。

### 1.3 解決へのアプローチ：MCPによる数値的介入
MCPを介してLLMをBlenderに直接接続し、エージェントが3D空間を座標や寸法といった「数値データ」として操作するアーキテクチャを提案する。
* **StaticDB:** 書き換え不可能な規制知識（物理法則、建築基準法）を扱う。
* **DynamicDB:** ユーザのフィードバックから成長する経験知識を蓄積し、推論コストを最適化する。

## 3. 提案手法

### 3.1 システムアーキテクチャ
システムの全体像は以下の4つの階層で構成される。

[Image: 提案システムの概念的アーキテクチャ図（AIコア層、MCP統合層、知識層、Blender環境層の連携）]

1. **AIコア層:** 「gpt-oss:20b」を採用し、プランナーとしてタスクを分解・推論する。
2. **MCP統合層:** 操作(T1/T2)、検査(T3)、知識(T4)といったツール群を標準化されたプロトコルで提供する。
3. **知識層:** **StaticDB**（規制知識）と**DynamicDB**（経験知識）の二層構造。
4. **Blender環境層:** Python API (bpy) を介して3Dシーンの状態を操作・取得する。

### 3.2 自律的な品質保証ループ
プロセスは「生成・検査・修正」のサイクルで構成される。
* **検査:** 検査器(T3)がStaticDBに基づき、頂点座標等を用いた厳密な数値検査を行う。
* **修正:** 検出された違反を具体的な数値情報（例：「0.5m浮いている」）としてLLMにフィードバックし、正確な修正アクションを立案させる。

### 3.3 実装詳細
[Image: システム実装詳細図（FastMCPサーバ、ソケットブリッジ、Blenderアドオンの通信フロー）]

Blenderの`bpy`がスレッドセーフでない制約を回避するため、MCPサーバとBlenderアドオン間に**ソケットブリッジ**（ポート9876）を介したハイブリッド通信を採用している。

## 4. 実験結果と考察

### 4.1 タスク設定と欠陥の定義
以下の5つの欠陥を含むシーンの自律修正を評価した。
1. **ドアの浮遊:** Z軸方向の物理的整合性違反。
2. **ドアの壁高超過:** 包含関係の違反。
3. **窓の壁高超過:** 幾何学的違反。
4. **窓とドアの重複:** 物理的干渉。
5. **採光面積不足:** 建築基準法違反。

### 4.2 知識蓄積とコスト効率の分析
[Image: 知識蓄積に伴うコスト削減グラフ（累積トークンとターン数の推移）]

* **Exp 1（初期）:** 9ターン、約22万トークンを消費。
* **Exp 9（後期）:** 2ターン、約9.1万トークンに減少（ターン数約78%減、トークン消費量約58%減）。
知識の蓄積（RAG）により、試行錯誤が削減され、ショートカットが可能になったことを示している。

### 4.3 自律性の非線形な関係
[Image: 知識蓄積による自律性の向上グラフ]

知識の増加に伴い、一時的に自律性が低下する「知識統合の停滞」が見られたが、ルール数が臨界点を超えたExp 9において、全5項目の自律修正（スコア5）を達成した。

### 4.4 行動変容の分析
[Image: ツール使用戦略の変化（試行錯誤から熟達へ）]

* **Exp 1:** 操作と検証を繰り返す「試行錯誤」が中心。
* **Exp 9:** 初動で「**ルール検索**」を行い、過去の経験則に基づいて一発で修正を行う「熟達」の挙動にシフトした。

## 5. おわりに
本研究は、MCPを用いた数値的介入と二層知識構造により、建築制約を満たすCADグレードの3Dモデル生成を実現した。今後は「家一軒」レベルの大規模生成や、Unity/Unreal Engineへの展開を視野に入れている。
